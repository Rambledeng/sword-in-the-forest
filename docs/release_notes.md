A wuxia soulslike vertical slice: the bamboo forest, outside the tavern, the tavern and its
landlady. The sword learns how fast you react and times its enemies' warnings to the challenge
you pick.

**Downloads:** `SwordInTheForest-<version>-windows.zip` (Windows 10/11, x86_64) and
`SwordInTheForest-<version>-linux.zip` (x86_64). Unzip and run `SwordInTheForest.exe` or
`SwordInTheForest.x86_64`. Keep the `data_SwordInTheForest_*` folder next to the executable.
Also on itch.io: https://rambledeng.itch.io/sword-in-the-forest

Languages: English, Nederlands, 简体中文. Keyboard and mouse or a gamepad.

Developer tools (F1 tuning, F2 director overlay, F3 developer menu) are off in these builds.
Start the game with `-- --dev` (or set `SWORD_DEV=1`) to turn them on.

See the README for controls and how the director works, and `docs/report.md` for the
simulation study. Code MIT; asset credits in `CREDITS.md`.

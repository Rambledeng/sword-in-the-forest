# History

Archives. Nothing here describes work to do, and sessions should not read these files unless a
question is about why something in the demo was built the way it was. Search them with grep
instead of reading them whole; together they are about 1,500 lines.

- `demo-spec.md`: the brief the demo (v0.1.0–v0.1.1) was built against, with its milestones,
  budget and glossary. Its "Game design" and "The adaptive director" sections are still the best
  description of the shipped rules.
- `demo-progress.md`: the session log for milestones M0–M5 and the follow-ups, newest first,
  with each milestone's decisions, known issues and playtest questions.

Entries rotated out of the root `PROGRESS.md` log go in `progress-<year>.md` here.
